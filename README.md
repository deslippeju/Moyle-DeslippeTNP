# Moyle-DeslippeTNP
This is code for analyses found in:
Moyle DM, Deslippe JR. 2024 Invasion alters plant and mycorrhizal communities in an alpine tussock grassland. Oecologia. 
Data are also stored permanently:
Julie Deslippe, & Darby Moyle. (2023). Plant community composition, soil nutrients, tussock morphometrics, C. rubra root colonisation, soil microbial PLFA and NLFA in 75 plots that vary in invasive Calluna vulgaris density, Tongariro National Park, New Zealand. Knowledge Network for Biocomplexity. doi:10.5063/F1DR2SZK.
